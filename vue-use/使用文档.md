# VueUse——一个大大提升开发效率的Vue3的工具库


## 1. 介绍

VueUse是一个基于 Composition API 实现的基本 Vue 组合实用函数的集合。

在使用element-plus时，发现element-plus的大部分方法都是直接使用的vue-use库中的函数。

官网地址：`https://vueuse.org/`

### 无缝迁移：同时支持Vue2和Vue3

- 支持按需引入：只取你想要的
- 强类型：用 TypeScript 编写，带有 TS Docs
- 灵活：可配置的事件过滤器
- 无需打包：支持CDN方式引入使用
- 功能丰富：截止目前180+功能任你选择 
- 友好的SSR：与服务器端渲染/生成完美配合 
- 互动演示：功能文档还附带互动演示 
- 附加插件：支持Router、Firebase、RxJS等多种插件

### 安装


```
# npm
npm i @vueuse/core
 
# yarn
yarn add @vueuse/core

# pnpm 
pnpm add @vueuse/core
```


### 导入使用

```vue
import { useMouse } from "@vueuse/core"

const { x, y } = useMouse()

console.log(x, y)
```
